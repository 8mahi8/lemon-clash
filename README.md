## 学校への公開方法：Google SitesにHTML全文を貼り付ける

**正式な配布方法はGoogle Sitesの「挿入 → 埋め込む → 埋め込みコード」に、ゲームHTMLの全文を貼る方式。** GitHub PagesのURL貼り付けや外部iframe参照は配布方法ではありません。

HTML全文は以下を実行して生成：

    node tools/build-embed.cjs

- **オフライン版の貼り付け元：** `dist/lemon-clash-embed.txt`
- **オンライン開発版の貼り付け元：** `dist/lemon-clash-online-lab-embed.txt`

同名の `.html` ファイルと `.txt` ファイルは**内容が完全一致**し、CSS・ゲーム用JavaScript・ルールをファイル内に含みます。Google Sitesの「埋め込みコード」に**ファイル内容全体**を貼り付けます。GitHubのファイルURL、GitHub PagesのURL、HTMLファイル名、ダウンロードURLを貼るのではありません。

オンライン用HTMLには、BRAWL・小国戦線で使用しているRTDBの接続先が開発版に設定されています。プレイヤーはルーム番号だけを使います。ただし、LEMON専用領域 `lemonClashRoomsV1` の実際のFirebase書き込み権限は未確認であり、ゲーム用JSに加えてFirebase SDKの読み込みとネットワーク接続が必要です。既存ゲームのデータや設定は変更しません。

Google Sites風のコード貼り付け検証：

    node --test tests/sites-paste.test.cjs

WebKitの貼り付け模擬テスト：

    node tests/sites-paste-webkit.cjs

この検証はGoogle Sites本体や学校iPadの実機動作を保証しません。検証完了まで公開版は更新しません。GitHub Pagesは開発中の確認リンクとして使える場合がありますが、学校向けの埋め込み手段とは区別します。

## カード一覧

| コスト | カード | 効果 |
|---|---|---|
| 1 | フェイント | 相手が通常防御なら、支払後エネルギー+3 |
| 1 | エネルギー泥棒 | 相手のチャージを無効化し、支払後エネルギー+2 |
| 1 | 見切り | 特殊攻撃カードのダメージを無効化（通常攻撃には無効） |
| 2 | 貫通攻撃 | 通常防御を貫通して1ダメージ |
| 2 | カウンター | 通常攻撃・連撃・オールインを防いで1反射 |
| 2 | 封印 | コスト3以下の特殊カードを無効化 |
| 3 | 連撃 | 2ダメージ。通常防御で完全に防がれる |
| 3 | 粉砕 | 通常防御に2ダメージ、その他は1 |
| 4 | 終焉の一撃 | 2ダメージ。通常防御には1 |
| 5 | オールイン | 3ダメージ。通常防御で完全に防がれる |
| 7 | 終局宣告 | 発動で即勝利。防御不可。両者同時使用は引き分け |

各カードは効果が失敗・無効化されてもコストを払い、使用済みになります。攻撃同士では両方の攻撃が成立し、両者HPが0になれば引き分け。

実装詳細：src/rules.js。テスト：tests/rules.test.cjs。

## 開発ブランチでのオンライン隔離試作

- `online.html`: 6桁の部屋作成・参加、秘密コミット、SHA-256照合、勝敗同期の試作画面。
- `src/online-protocol.js`: 同時選択用のコミット・公開検証ロジック。
- `src/online-app.js`: 既存RTDB上のLEMON専用領域＋端末ローカルプレイヤーIDを使う友人用通信処理（専用Authプロジェクトモードも保留）。
- `firebase/lemon-clash-lab.rules.json`: **専用テスト環境だけ**の権限ルール。
- `tests/online-protocol.test.cjs`: コミット改ざん検出等の単体テスト。
- `tests/online-emulator-webkit.cjs`: 2台WebKit＋ローカルFirebaseエミュレーターの統合試験。
- `dist/lemon-clash-online-lab-embed.txt`: **Google Sitesの埋め込みコード欄にそのまま貼り付けるHTML全文**（同名 `.html` と同一内容）。

**重要：まだ「実オンライン対戦の動作確認済み公開版」ではない。** `src/firebase-config.js` は学校で動作中のRTDB接続先を設定済み。Google Sites埋め込みHTMLを使用する2つのChromium画面＋模擬RTDBで9ターンの完走を確認したが、実RTDBの権限と学校iPad Safariは未確認。Google DriveにHTML全文TXTの接続テスト版を保存し、実機確認待ち。BRAWLと小国戦線のソース・Firebaseデータ・Rulesは変更しない。詳しくは `docs/ONLINE_1V1.md`。

## オンライン対戦の設計メモ（今後）

Firebase RTDBを使い、専用ルームでお互いの行動を秘密で確定し、**両者のコミット完了後に公開・検証**する方式を検討。

重要：クライアントが未公開行動を直接読み取れる設計にしない。アクション+ターン+十分長いランダムsaltをSHA-256でcommitし、双方のcommit後にrevealする（commit-reveal）。同時にRTDB Rules / Authでユーザー、部屋、ターン、書込権限を保護する。部屋番号のみは認証ではない。

BRAWLの本番Firebase設定・Rules・公開Google Sitesには触れず、別の試験環境でオンライン動作を検証する。
