# 🍋 LEMON CLASH RC8｜バランスV2／カード説明改修

2026-10-26 — **学校iPad実機未検証・Google Sites本番未変更・開発候補**

## 実装した内容

- 既存11枚から特殊カード15枚に拡張。
- **粉砕（3）**：相手の通常防御にのみ2ダメージ。他は0。見切り・封印で無効。
- **終焉の一撃（4）**：2ダメージ、通常防御でも1ダメージ。相手のチャージを中断。
- **封印（2）**：終局宣告以外の特殊カードを無効化。成功時にエネルギー+1（封印同士は相互無効で増加なし）。
- **カウンター（2）**：通常攻撃・連撃・オールインと、新カード生命吸収・チャージ狩りの**攻撃ダメージだけ**を全反射。付随効果・回復・エネルギー減少は反射しない。
- **生命吸収（新・3）**：1ダメージ。命中したらHP+1（最大3）。シールド命中でも回復。回復は自分への同ターンダメージ適用より先。
- **チャージ狩り（新・2）**：1ダメージ。相手がチャージなら中断し、さらにエネルギー-1（下限0）。
- **生命燃焼（新・1）**：HP-1（シールド無視）、エネルギー+3（コスト1後の純増+2）。HP1では使えない。封印されると自傷・獲得は発生しない。
- **装甲展開（新・4）**：壊れるまで残るシールド2。同じターンの被ダメージより先に獲得し、超過ダメージのみHP減少。封印されると失敗。終局宣告を防げない。
- 攻撃などでシールドを削ってもチャージ中断効果は発動（ヒットとして処理）。
- 元のHP最大3、初期エネルギー1、エネルギー最大10、使い切り制、サドンデス3択を維持。
- **オンライン**：両端末のHP/エネルギー/カード使用履歴に加えシールドも同期検証。RC6/RC7と同部屋に入らないようルームプロトコルを **v3** へ更新。
- **UI**：双方のHPの隣に残シールドを表示（残量0では省略）。カードタップ詳細を効果・主な防御方法まで短文で記載。貫通攻撃のカウンターに関する説明は削除、生命吸収の「シールド命中でも回復」は内部動作のみ記載。生命燃焼をHP1で選択した場合は専用の制限メッセージ。
- **既存ルームチャット**：RC7試験版のルームチャットコードを継承。通信方式、接続先、チャット権限は変更しない。
