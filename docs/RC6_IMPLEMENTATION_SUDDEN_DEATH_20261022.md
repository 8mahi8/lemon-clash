# LEMON CLASH RC6 — バランス確定 / サドンデス3択 / 封印拡張
2026-10-22（開発ブランチ限定）

## 今回確定したルール
- **サドンデス**：同時HP0、または両者の同時終局宣告で発生。そこで試合は終了せず、同時に3択を選ぶ。
  - 攻撃 `sd_attack` は崩しに勝つ。
  - 防御 `sd_guard` は攻撃に勝つ。
  - 崩し `sd_break` は防御に勝つ。
  - 同じ手は決着なしでサドンデス再戦。同じ手が続いても何度でも再選択。
  - サドンデス中はHPやエネルギー、通常カードや特殊カードを使用せず、3択のみで勝敗確定。
  - **同時公開方式は本編と共通**で、双方のハッシュcommit確定までは手を公開しない。
- **封印**：2コスト、終局宣告以外の全特殊カードを無効化。発動不能になった特殊カードのコストと使用済み扱いは維持。通常アクションは無効化できない。
- その他はRC5のバランスを維持：初期HP3、初期エネルギー1、最大10、通常攻撃は相手のチャージ獲得を妨害、オールイン5、終局宣告10、連撃3、カウンター2（通常攻撃・連撃・オールインのみ防御＋1反射）。
- **カード数は11のまま。** サドンデスはカードではなく別の決着フェーズ。

## 変更と検証
- `src/rules.js`：サドンデスの3すくみ、無制限再選択、引き分け時のフェーズ移行、封印対象拡張。
- `src/online-app.js`：サドンデスをFirebase stateとして読み込み、予想値と照合。3択のみを出し、通常カードを隠し、リザルトや再戦と連携。
- `src/app.js`：1台交代プレイとBOTプレイでもサドンデス3択に対応。
- `src/online-protocol.js`：room protocol **v2**。RC2/RC5との同室混在を拒否。
- `online.html`・`index.html`：画面見出しの切り替え。
- `firebase/lemon-clash-lab.rules.json`：**専用・非本番エミュレーター向け**ルールのみv2対応。学校で使用中の本番Firebase設定やRulesは一切変更しない。
- 終局宣告／封印／通常攻撃／3すくみ全6パターン／同じ手の継続／状態同期／2人模擬対戦／秘密commit／再戦を含む**45/45**テスト成功（GitHub内容を読み込んだ実ゲーム処理・模擬Firebaseを利用）。
- Google Sites用に**全HTML+ゲームJSを1ファイルへインライン化**し、4本のJS構文検査、封印・サドンデス・プロトコルv2・必要IDの有無を検証。GitHub読み戻し一致。
