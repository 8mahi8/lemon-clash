# 🍋 LEMON CLASH RC7 — ルームチャット追加（開発候補）
2026-10-26

## 変更範囲
- **RC6のHP・エネルギー・カード・特殊効果・サドンデス・対戦プロトコル v2は変更しない。**
- 対戦中と参加待ちに開閉式のチャットパネルを表示。
- 同じルームのホスト / ゲストが互いのメッセージを受信。
- Firebase Realtime Database の既存 `lemonClashRoomsV1/{roomCode}/chatMessages` に保存。**他ゲームの名前空間、Firebase本番ルール、公開中のGoogle Sitesは未変更**。
- 新しい専用サーバー・Firebaseプロジェクトは使用しない。

## データ・UI
- 各メッセージ: `{seat:"host"|"guest", text, at}`。本人の表示は「自分」、相手は「相手」。
- 最大120文字、空白だけは送れない。同一端末からの連続送信は1.5秒以上空ける。
- Firebase の transaction で競合を解決し、最新20件のみ残す。
- DOM の textContent で表示し、任意HTMLとして解釈しない。
- チャットだけ更新された場合は対戦手札を描画し直さない。待機中、対戦中、ゲーム終了後も会話可能。
- 再入室で同じルームの最新20件を表示。退出後はパネル、入力、送信ボタン状態を初期化。
- 日本語IME変換の Enter は送信扱いにしない。送信失敗時は入力を残し、エラーを表示。

## テスト
- ルール・マッチアップ・模擬Firebaseによる二人対戦テストを実行。
- 追加テスト: 待機室からの送信、ゲストのリアルタイム受信、既存手札選択維持、退出/再入室、HTMLタグの文字列表示、参加者以外からの書込拒否（**模擬ルールのみ**）、空文・文字数上限・最新20件・連投制限。
- 単体Google Sites貼り付けコード: `release-candidates/LEMON_CLASH_RC7_RoomChat_GoogleSites.txt`

## 実機・本番の留保（重要）
- **本番Firebase RTDBのアクセスルールはこの開発では確認・変更していない。** `chatMessages` の書き込みが現在のルールで拒否される可能性がある。送信エラー表示あり。権限を最小化したい場合はルールの検証/変更が別途必要。
- 共有RTDBでは `localStorage` のローカルプレイヤーIDを使用しているだけで、真正なログイン認証は実施していない。チャットを機密会話に使わない。
- 学校iPad Safari / Google Sites実貼り付け / 実Firebaseでのチャット2端末疎通は未検証。単体テストと模擬Firebaseは実機を代替しない。
- RC6はGitHub内の既存候補としてそのまま保存。RC7は試験用候補であり、自動公開しない。RC2公開版、`main`、Firebaseルール・本番データ、既存RC6 PRは変更しない。

## 学校向け確認手順
1. 既存Google Sites公開用HTMLを触らず、**別テストページ**にRC7の .txt 全文を「埋め込み → 埋め込みコード」へ貼り付ける。
2. RC7同士の2台で新しい6桁ルームへ接続する。
3. ホストの待機室で投稿 → ゲスト参加で過去メッセージの表示確認 → 両方向でチャット。
4. 手札を選んだ状態でチャットを受信し、選択状態が消えないことを確認。
5. 通常対戦、終盤、サドンデス、再戦、退出/再入室の後にもチャットと対戦が正常であることを確認。
6. Firebase権限エラーが出た場合は、現在の本番ルールを把握するまで公開版へ反映しない。
