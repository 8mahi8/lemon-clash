# LEMON CLASH — バランスV2と全カード説明文の監査（実装前）
2026-10-26 / 設計資料のみ / ゲームコード未変更

## 目的と範囲

ユーザーと合意したバランス変更と、実際の現行ソース（src/rules.js、src/online-app.js）から確認した説明不足を整理する。
ゲームの既存11枚＋新規4枚＝特殊カード15枚。基本行動3種類とサドンデス3択も説明を確認する。
この文書は**未実装の新カードや修正を現行ゲームの仕様と混同しないための設計案**である。

### ユーザー確定の変更（ゲームルールの実装は今後）

- 終焉の一撃（4）：現在の2ダメージ、通常防御時1ダメージは維持。チャージ中断を追加。
- 封印（2）：終局宣告以外の特殊カードを無効化。封印成功なら自分のエネルギー+1。
- カウンター（2）：現在の対応攻撃のダメージを0にし、**そのダメージ数だけ**反射。エネルギー減少、チャージ中断、回復等の付随効果は反射しない。対応対象に新カード「生命吸収」「チャージ狩り」を追加。
- 生命吸収（新・3）：特殊攻撃、1ダメージ、命中時HP+1（最大HP3）、通常防御・カウンター・見切り・封印で無効。相手のシールドに当たっても回復、命中時回復を自分への被ダメージより先に反映。
- チャージ狩り（新・2）：特殊攻撃、通常1ダメージ、相手がチャージを選んだ場合はチャージ中断＋相手のエネルギーをさらに1減少（下限0）。通常防御・カウンター・見切り・封印で無効。
- 生命燃焼（新・1）：HP-1（シールド無視）、エネルギー+3（支払コスト1で純増+2）。HP1では使用不可。使用は1回限り。
- 装甲展開（新・4）：永続シールド2を獲得、同じターンのダメージ前に有効化、シールドから先にダメージを吸収、超過分だけHPに入る。封印は防げない／封印で無効化、終局宣告の即勝利は防げない。
- 全ての特殊カードは従来と同じく各試合一回限り。無効化されても支払コストと使用済み状態は戻らない。
- 最大HP3、エネルギー上限10、既存の基本行動とサドンデスの勝敗は維持。

## 現行ソースの説明文の問題（ソース由来）

- 貫通攻撃の「通常防御を貫通して1ダメージ」だけでは、見切り・封印で無効、カウンターは無効という相性がわからない。
- 粉砕の「通常防御に2ダメージ、それ以外には1ダメージ」は、見切り・封印で**0ダメージ**になる点を省略しており誤認されやすい。
- 通常防御の「通常攻撃と一部の特殊攻撃を防ぐ」は、何を防ぎ、何には効かないのか分からない。
- 見切りの「特殊攻撃カードを無効化」は、非攻撃の特殊カード（封印、フェイント、装甲展開など）まで止めると誤解されうる。現行コードは特殊攻撃の「与ダメージを0」にする。
- カウンターは現在「通常攻撃・連撃・オールイン」だけに反応。貫通攻撃、粉砕、終焉の一撃には反応しない。新調整により反射ダメージ量が変わる。
- 通常攻撃を防ぐのは通常防御・カウンター。見切り・封印では防げない。
- 既存の特殊カードは相手の「封印」によって基本的に無効化される（例外は終局宣告）。
- 現行Web画面は、カードをタップするとカード詳細欄に move.description の単一段落を表示。カードのサムネイル本体は効果文を非表示にしている。長文化するなら詳細欄に「効果」「対策」「注意点」を分けるのが適切。

### サドンデスの3択

現行文言は十分。必要なら簡潔に次のとおり統一する：
- 攻撃：崩しに勝ち、防御に負ける
- 防御：攻撃に勝ち、崩しに負ける
- 崩し：防御に勝ち、攻撃に負ける

## 説明UIの設計方針

- カードの絵・コスト・名前は現在の手札レイアウトを維持。
- カードタップで詳細パネルに「効果」「対策」「注意」を**別行**表示。古いiPad横向きでもカードや確定ボタンを押し下げすぎないよう、必要に応じて詳細エリアのみ高さ制限・スクロール。
- 例：貫通攻撃 → 「効果：通常防御を貫通し1ダメージ」「対策：見切り・封印で無効」「補足：カウンターは効かない」。
- 例：粉砕 → 「効果：通常防御の相手に2、その他に1ダメージ」「対策：見切り・封印で無効」。**防御を除く全ての行動に必ず1ダメージと受け取られないようにする**。
- 文章の情報は対戦エンジンの実際のルールと同一ソースを参照する。カード説明だけ変更してゲーム挙動が違う状態にしない。
- 追加カードの反射・封印・命中の相性は自動テスト化し、説明と一致させる。
- 対戦公開版RC2、現行RC6およびRC7のルールとGoogle Sites本番はそのまま保持。

## 実装前に開発側で確認すべき細部

1. 封印同士の同時使用では互いに封印が無効になる現行動作。V2の「封印成功時エネルギー+1」を相互封印にも付与するか。**推奨：自分の封印が無効ならボーナスなし**。ユーザーの最終確認またはシミュレーションで判断。
2. シールドでHPダメージが0になっても通常攻撃・終焉の一撃・チャージ狩りによるチャージ中断を適用するか。**推奨：攻撃がヒットした扱いなら中断**。ユーザー確定前の提案。
3. 生命吸収はシールドにダメージが入った場合もHPを回復（ユーザー確定）。シールドをダメージで削り切った場合の残余はHPへ。
4. 生命燃焼の自傷はシールドを無視する（ユーザー確定）。封印でそのカードが無効ならコストとカード消費のみで自傷効果は発生しない案をテストする。
5. カウンターは「対象の攻撃ダメージ」を反射する（ユーザー確定）。シールドは返されたダメージも吸収する一般ルールとして検証。
6. 最大HP3、エネルギー上限10、ゲーム勝敗・サドンデス処理との整合性を確認。
