# 🍋 LEMON CLASH — RC4 オールイン5コスト（2026-10-21）

## ユーザー承認の調整
- オールイン **4コスト → 5コスト**。
- 理由：通常攻撃でHP3を削るには3回攻撃を選んでその都度防御を読まなければならないが、オールインは1回の命中で3HPを削れる。コスト4のままでは最短4ターンで撃て、通常攻撃だけでの最短5ターンよりも速い。
- オールインを5コストにすると、初期エネルギー1から **チャージ4回＋オールイン1回＝最短5ターン**。
- RC3でユーザーが承認した「通常攻撃がチャージに命中するとそのターンのチャージ+1が中断」も継続。通常攻撃を受けたターンはチャージが遅れ、オールインの準備はより危険になる。
- HP3、他カードのコスト・効果、オールインの3ダメージ、通常防御・見切り・カウンターで止まる仕様、使い切り、終局宣告7、相打ち引き分けは変更しない。
