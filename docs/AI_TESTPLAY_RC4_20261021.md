# 🍋 LEMON CLASH RC4 — AI戦術テストプレイ (2026-10-21)

## 対象・方法
- `src/rules.js`（開発ブランチ / Git blob `0f97052c17e9b9dac9c89a10f91784ec298b0389`）から実際の `createGame`, `availableMoves`, `validMove`, `resolveTurn` を読み込み、ルールの再実装をせずに対戦実行。
- RC4: HP3、開始エネルギー1、通常攻撃が相手のチャージ+1を中断、オールイン5コスト、終局宣告7コスト。
- 戦術6種×相手6種×各300試合 = **10,800試合**。各試合最大35ターン、簡易乱数生成器の固定シードで対戦を再現。35ターン到達は勝ち負けとは別に未決着。
- 戦術6種: ①通常攻撃連打（エネルギー0でチャージ）、②オールインのためチャージ優先、③終局宣告のためチャージ優先、④防御寄り確率戦術、⑤通常行動と特殊カードを混合した確率戦術、⑥特殊攻撃寄り確率戦術。
- **重要**: 手作りの簡易AIの成績。人間・熟練プレイヤーの勝率、理論最善手・ナッシュ均衡の計算ではない。ブラウザ操作や実Firebase接続の実機テストでもない。

## 結果（通常攻撃側を左とした一方向の計測、300試合ずつ）
| 左側の戦術 | 右側の戦術 | 左勝 | 左負 | 引き分け |
| --- | --- | ---: | ---: | ---: |
| 通常攻撃中心 | オールイン一直線 | 300 | 0 | 0 |
| 通常攻撃中心 | 終局宣告一直線 | 300 | 0 | 0 |
| オールイン一直線 | 終局宣告一直線 | 300 | 0 | 0 |
| 通常攻撃中心 | 混合基本 | 243 | 17 | 40 |
| 通常攻撃中心 | 防御寄り | 265 | 21 | 14 |
| 通常攻撃中心 | 特殊攻撃重視 | 267 | 0 | 33 |

防御寄りAIは一般的な混合手に弱く、通常攻撃を適切に毎回読むだけのAIではないため、上記成績から「通常攻撃が絶対的最強」と断定しない。防御寄りvs防御寄りは300試合中150試合が35ターン未決着。プレイヤーの行動ポリシーによって試合が長期化し得る。

## 追加の「相手が攻撃すると分かっている」対策テスト
対攻撃特化AIは、相手エネルギーが1以上なら通常防御、相手が0なら自分のエネルギーがあれば通常攻撃、なければチャージを選ぶ（攻撃タイミングを読む簡易ボット）。
- 対攻撃特化 vs 通常攻撃中心：**対攻撃側が8ターンで勝利**（RC4）。
- 対攻撃特化 vs 終局宣告一直線：**終局宣告側が7ターンで勝利**。防御し続けるだけだと終局宣告を止められない。
- したがって、攻撃連打にも弱点はあり、単純な1つの戦術が全てに勝つとは示されていない。

## 旧RC2との厳密な比較（同じ固定戦術の実ゲームルールを用いた1対戦）
- **RC2**：通常攻撃中心 vs オールイン一直線 → **オールイン側が4ターンで勝利**。
- **RC4**：同じ戦術同士 → **通常攻撃側が5ターンで勝利**。
- RC2: オールイン4コスト、通常攻撃でチャージは中断しない。RC4: オールイン5コスト、通常攻撃でチャージ中断。2条件同時に変わっているため、勝敗の逆転をどちらか一方の効果だけに帰属させない。
- 終局宣告一直線はどちらの版でも通常攻撃中心に5ターン目で負ける。チャージ中断はエネルギー量に差を生むが、この固定マッチアップの勝敗を変えたわけではない。

## 暫定レビュー
- RC4で「チャージし続ければ最も速く、効率よく勝てる」という単純な戦術は抑えられた。
- 通常攻撃への防御、通常防御に対するチャージ、チャージを見た通常攻撃、という基本の読み合いは機能している兆候がある。
- ただし、現在の確率戦術は人間のように相手の癖を継続学習しない。特殊カードの価値、特に封印・連撃の強さや終局宣告の優位性は**未確定**。
- 今回は**調査・シミュレーションのみ**。RC4を公開していない。学校Google Sitesで動作しているRC2、Firebase、`main`、その他のゲームに手を加えない。
